API do PizZap

Página só da equipe (acesso com a chave do config.py). Clique em Enviar e a resposta aparece logo abaixo do botão, com o código HTTP: 200 ou 201 = deu certo, 400 = dados inválidos, 404 = não encontrado, 409 = já existe. Sair

1. Cadastrar no banco POST

Novo ingrediente /api/banco/ingredientes (tabela Ingredientes). densidade em g/ml é opcional: com null, o ingrediente aparece só em gramas.


  


  

    
Nova medida caseira /api/banco/medidas (tabela MedidasCaseiras).
      volume em ml. A medida nova já passa a ser usada na conversão das receitas.

    
    

      
      
    

    

  

  

    
Novo sabor /api/banco/recheios (tabelas Recheios e RecheiosXIngredientes).
      Cada ingrediente vai com o id (veja em /api/banco/ingredientes, inclusive os que
      você cadastrou acima) e os gramas por cm² de pizza. Referência: molho 0.08, mussarela 0.1 a 0.2,
      orégano 0.002. O sabor já aparece no formulário.

    
    

      
      
    

    

  

  
Para corrigir ou apagar um cadastro, use o MySQL Workbench e reinicie o servidor.
